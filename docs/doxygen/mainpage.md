# Loci C++ API Reference

This is an experimental Doxygen pass over the C++ header surface of the Loci
source tree.

The current configuration intentionally includes only C++ header files:

- `.h`
- `.hh`
- `.hpp`

The Loci language sources are intentionally excluded here:

- `.lh`
- `.loci`

Those files are expected to be handled by the Loci documentation parser rather
than by Doxygen.

Generated output is written to `OBJ/docs/api-cpp/html/`.
